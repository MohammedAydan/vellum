التحقق العملي#

يعمل تطبيقا الاختبار لكلا المجموعتين البرمجيتين مقابل API حي مدعوم بقاعدتَي PostgreSQL الحقيقيتين للتحكم والبيانات. لم يُستخدم أي تقليد أو محاكاة أو تخطٍّ. جميع الأرقام أدناه مأخوذة حرفيًا من ملف الشواهد.

الأوامر والنتائج#

BASH
# اختبار JavaScript / TypeScript الحي (CLI ولوحة التحكم يستخدمان نفس السيناريوهات)
corepack pnpm --filter @vellum/js-testbed-app run verify:live
# → 12/12 نجاح، رمز خروج 0 — شُغّل مرتين في نفس عملية API

# اختبار Flutter / Dart الحي عبر CLI
cd examples/flutter_testbed_app
PATH="/home/ubuntu/projects/document-db/.tools/dart-sdk/bin:$PATH" \
  VELLUM_API_BASE_URL=http://127.0.0.1:8080 dart run bin/run_live_testbed.dart
# → 12/12 نجاح، رمز خروج 0
PATH="/home/ubuntu/projects/document-db/.tools/dart-sdk/bin:$PATH" dart test
# → نجاح (1/1 تغليف E2E حي، 12 سيناريو، ~16 ثانية)

# بوابات مجموعة Flutter
cd sdks/flutter && dart analyze --fatal-infos --fatal-warnings && dart test
# → "No issues found!" · 48 اختبارًا ناجحًا

يُنشئ كل تطبيق مستأجره ومشروعه ومفاتيحه وقواعده وإعدادات المصادقة الخاصة به بمعرّفات فريدة لكل تشغيل، ثم ينظّفها. تُطبع فقط الحالة وزمن الاستجابة؛ وتُخفى الرموز والمفاتيح وعناوين قواعد البيانات.
