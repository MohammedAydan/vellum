المرجع / واجهات الحزم البرمجية

واجهات الحزم البرمجية (داخلية)#

هذا مرجع داخلي لمكتبات packages/* في Monorepo. نُقلت التوقيعات من ملف src/index.ts لكل حزمة ومن ملفاتها المصدرية. أما المكتبات الموجَّهة للعملاء فاستخدم JavaScript SDK وFlutter SDK بدلًا منهما.

WARNING

حزم داخلية — ليست الـ SDK العامة

المكتبات أدناه هي لبنات بناء داخلية تستخدمها apps/api ومجموعات SDK. ليست سطح منتج عام مدعوم: فقد تتغير صادراتها بين الإصدارات، وبعض المسارات (أبرزها منشئات القيم الموسومة في @vellum/core ومؤشرات @vellum/query-engine) حرجة بالنسبة لتنسيق الإرسال. يجب أن تعتمد كود التطبيقات على @vellumdb/sdk-js أو على HTTP المباشر، لا على هذه الحزم مباشرة.

قواعد الحدود المعمارية#

القاعدةالأثر على هذه الحزم
حدود Monolith المعياريكل منطق العمل يقع في packages/* المستقلة عن الأطر. وتطبيقات التوصيل مجرد محولات رقيقة — بلا تقييم AST أو تسلسل إرسال أو تحويل SQL في معالجات المسارات/الواجهة.
مستويان للبياناتdatabase-control (المستخدمون، المؤسسات، المشاريع، البيئات، تجزئات المفاتيح، مجموعات القواعد، القياس، التدقيق) وdatabase-data (المستندات، تعريفات/مداخل الفهارس، outbox، المعاملات) منفصلان فيزيائيًا ومنطقيًا. ولا تعتمد التهيئة أو التحقق من المفاتيح على واجهة المستندات العامة أبدًا.
عزل المستأجرينكل عملية في مستوى البيانات تتطلب (projectId) (TenantContext). تربط معاملات PostgreSQL الإعدادات SET LOCAL statement_timeout='5000ms' وapp.current_project_id كي يفشل RLS بانغلاق (fail closed).
صفر DDL للعملاءفهارس المستأجرين المركّبة هي صفوف في document_indexes + document_index_entries بمفاتيح فرز ثنائية — ولا يُنفَّذ CREATE INDEX على documents أبدًا.
AST حتميلا eval()/new Function()؛ يتحقق @vellum/authorization من شجرة قواعد v1 ويقيّمها بشكل متزامن.
ترقيم بالمؤشر فقطمؤشرات غير شفافة موقّعة HMAC-SHA256 من @vellum/query-engine؛ بلا OFFSET.
صفر خدمات حالة خارجيةPostgreSQL فقط. الوقت الفعلي = LISTEN/NOTIFY + outbox دائم؛ والمخاب/حدود المعدل هي TTL داخل العملية+z حالة مدعومة بـ PostgreSQL.

الحزم الثماني أدناه كلها مستقلة عن الأطر (لا تستورد Hono أو Next.js أو React). وتستخدم عدة منها أدوات Node المدمجة (node:crypto، pg) ولذلك تستهدف الخادم/وقت التشغيل، لا المتصفح.
