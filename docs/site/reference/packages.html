Reference / Package APIs

Package APIs (internal)#

This is an internal reference for the monorepo libraries under packages/*. Signatures are transcribed from each package's src/index.ts and its source files. For the customer-facing libraries use JavaScript SDK and Flutter SDK instead.

WARNING

Internal packages — not the public SDK

The libraries below are internal building blocks used by apps/api and the SDKs. They are not a supported public product surface: their exports can change between releases, and some paths (notably @vellum/core tagged-value constructors and @vellum/query-engine cursors) are wire-format critical. Application code should depend on @vellumdb/sdk-js or plain HTTP, not on these packages directly.

Architectural boundary rules#

RuleConsequence for these packages
Modular-monolith boundaryAll domain logic lives in framework-agnostic packages/*. The delivery apps are thin adapters — no AST evaluation, wire serialization or SQL compilation in route handlers/UI.
Dual data planedatabase-control (users, orgs, projects, key hashes, rulesets, metering, audit) and database-data (documents, index defs/entries, outbox, transactions) are physically/logically separate. Bootstrap and key verification never depend on the public document API.
Tenant isolationEvery Data Plane operation requires (projectId) (TenantContext). PostgreSQL transactions bind SET LOCAL statement_timeout='5000ms', app.current_project_id so RLS fails closed.
Zero customer DDLTenant composite indexes are rows in document_indexes + document_index_entries with binary sort keys — never CREATE INDEX on documents.
Deterministic ASTNo eval()/new Function(); @vellum/authorization validates and evaluates the v1 rules AST synchronously.
Cursor-only paginationHMAC-SHA256 signed opaque cursors from @vellum/query-engine; no OFFSET.
Zero external stateful servicesPostgreSQL only. Realtime = LISTEN/NOTIFY + durable outbox; caches/rate limits are in-process TTL plus PostgreSQL-backed state.

All eight packages below are framework-agnostic (none import Hono, Next.js, or React). Several use Node builtins (node:crypto, pg) and therefore target the server/runtime, not the browser.

@vellum/core#

Responsibility: locked limits, canonical error hierarchy, path parser, tagged wire format, and order-preserving sort-key encoder. Pure, dependency-light, and the lowest-level package in the graph (@vellum/api-contract, @vellum/authorization, @vellum/query-engine, @vellum/storage, @vellum/realtime all depend on it). Barrel exports limits, errors, paths, wire-format, sort-key.
