# CRUD ومسارات المستندات

كل مورد في مستوى البيانات يُعنون بمسار قياسي UTF-8 مفصول بـ `/`. تتناوب المسارات بين مقاطع المجموعات ومقاطع معرّفات المستندات.

## السيناريو

أنت تنمذج عميلًا وطلباته: مستند واحد عند `users/u_123`، ومجموعة فرعية للطلبات عند `users/u_123/orders/ord_456`. تنشئ المستخدم، وتعدّل حقلًا بطابع زمني من الخادم، وتحمي التعديل بشرط إصدار (version precondition)، ثم تقرأ المستند مع بياناته الوصفية.

## قواعد المسار

| النوع | المقاطع | أمثلة |
| :--- | :--- | :--- |
| مستند | زوجي، 2–10 | `users/u_123`, `users/u_123/orders/ord_456` |
| مجموعة | فردي، 1–9 | `users`, `users/u_123/orders` |

يسمح مسار بعمق 10 بخمس مجموعات متداخلة. بالنسبة إلى `users/u_123/orders/ord_456`:

| العنصر | القيمة |
| :--- | :--- |
| `path` | `users/u_123/orders/ord_456` |
| `collectionPath` | `users/u_123/orders` |
| `collectionGroup` | `orders` |
| `documentId` | `ord_456` |
| `pathDepth` | `4` |

### قيود المقاطع

- بحد أقصى **1,500 بايت** لكل مقطع (UTF-8).
- لا `/` ولا بايت NUL ولا أحرف تحكم ASCII (`0x00`–`0x1F`).
- تُرفض `.` و`..`.
- المقاطع المطابقة للنمط `^__.*__$` (مثل `__name__`) محجوزة لبيانات محرك الأعمال ويُرفض استخدامها في مسارات المستخدمين.

:::warning
تجاوز حد العمق يُثير `INVALID_DOCUMENT_PATH` (400). المقاطع الطويلة جدًا أو المحجوزة تُنتج الرمز نفسه.
:::

## مراجع المستندات والمجموعات

```ts
import { createClient } from "@vellum/sdk-js";

const db = createClient({ projectId: "<YOUR_PROJECT_ID>", apiKey: "<YOUR_API_KEY>" });

// مرجع مستند (عدد زوجي من المقاطع).
const user = db.doc("users/u_123");

// مرجع مجموعة (عدد فردي من المقاطع)، ثم مستند بداخلها.
const orders = db.collection("users/u_123/orders");
const order = orders.doc("ord_456");

// مجموعة فرعية متداخلة من مرجع مستند موجود.
const events = user.collection("events"); // users/u_123/events
```

المراجع عبارة عن أدوات بناء غير قابلة للتعديل؛ استدعاء طريقة على مرجع يُرجع قيمة جديدة بالحالة المحدّثة عند الاقتضاء.

## create وset وupdate وdelete

```ts
// create — يفشل بـ ALREADY_EXISTS إذا كان المسار مشغولًا.
await user.create({ name: "Ada", role: "admin" });

// set — يستبدل افتراضيًا، أو يدمج بعمق مع { merge: true }.
await user.set({ name: "Ada Lovelace" }, { merge: true });

// update — يعدّل الحقول المقدّمة فقط؛ ويدعم تحويلات الحقول.
await user.update({ lastSeenAt: fieldOp.serverTimestamp() });

// delete — حذف ناعم (علامة حذف + حدث في صندوق البريد).
await user.delete();
```

يُرجع `create` و`set` المستند المخزّن (المسار، ومسار المجموعة، ومعرّف المستند، والبيانات، و`version`، و`createdAt`، و`updatedAt`). أما `update` فيطبّق المفاتيح المقدّمة فقط، ويترك المفاتيح الغائبة دون تغيير.

```ts
// القراءة تُرجع المستند مع بياناته الوصفية التي يديرها الخادم.
const snap = await user.get();
console.log(snap.path, snap.version, snap.exists, snap.data());
```

### التحكم المتفائل في التزامن بـ `ifVersion`

لكل مستند `version` تتزايد رتيبيًا. مرّر الإصدار المتوقع كشرط مسبق لرفض الكتابة إذا غيّر كاتب آخر المستند أولًا:

```ts
const snap = await user.get();
await user.update({ status: "approved" }, { ifVersion: snap.version });
// إذا رفع كاتب آخر الإصدار، تُثير هذه العملية FAILED_PRECONDITION (412).
```

يقبل كل من `set` و`delete` خيار `ifVersion` نفسه. يُرجع فشل الشرط المسبق `FAILED_PRECONDITION` مع `expectedVersion` و`actualVersion` في تفاصيل الخطأ. للذرية عبر مستندات متعددة مع شروط مسبقة، استخدم [المعاملات](./batch-and-transactions.md).

## أساسيات تنسيق الأسلاك الموسوم

تُخزَّن أنواع JSON الأصلية (`null`, `boolean`, `string`, `number` المنتهي، `array`) مباشرةً حتى تتمكن فهارس `jsonb_path_ops` في PostgreSQL من استخدامها دون حمل إضافي. أما الأنواع الموسّعة فتستخدم المفتاحين المحجوزين `$t` (الوسم) و`$v` (القيمة):

| النوع المنطقي | التمثيل |
| :--- | :--- |
| `int64` | `{ "$t": "int", "$v": "-9007199254740993" }` |
| `timestamp` | `{ "$t": "ts", "$v": "2026-11-15T14:30:00.123Z", "$ms": 1794753000123 }` |
| `reference` | `{ "$t": "ref", "$v": "users/u_123" }` |
| `bytes` | `{ "$t": "bytes", "$v": "SGVsbG8=" }` (Base64) |
| `geopoint` | `{ "$t": "geo", "$v": { "lat": 30.0444, "lng": 31.2357 } }` |
| خريطة مستخدم تحتوي `$t` | `{ "$t": "map", "$v": { ... } }` (هروب تلقائي دون فقدان) |

- يجب أن تكون الأرقام منتهية؛ يُرفض `NaN` و`Infinity`.
- الحد الأقصى لتداخل الكائنات/Mصفوفات هو 20 مستوى (`MAX_NESTING_EXCEEDED`).
- الحد الأقصى لطول اسم الحقل 256 حرفًا، ولا يمكن أن يحتوي على أحرف تحكم (`INVALID_FIELD_NAME`).
- لا يتجاوز المستند المتسلسل 1 MiB (`DOCUMENT_TOO_LARGE`).

:::tip
يجب أن تكون المراجع (`$t: "ref"`) مسارات قياسية صالحة داخل المشروع والبيئة نفسيهما. هي سلاسل مسارات عادية على مستوى الأسلاك — لا يجلب لك VELLUM المستند الهدف.
:::

## الأخطاء الشائعة

- **الخلط بين مسار المستند ومسار المجموعة.** مسار المستند عدد مقاطعه زوجي؛ ومسار المجموعة فردي.
- **استخدام مقطع محجوز.** الأسماء مثل `__name__` هي بيانات وصفية للمحرك ويُرفض استخدامها في مسارات المستخدمين.
- **توقّع أن `create` متكرر النتيجة.** يفشل بـ `ALREADY_EXISTS`؛ استخدم `set` عند الرغبة بالاستبدال.
- **افتراض أن `delete` يحذف الصف فورًا.** إنه حذف ناعم (علامة حذف)، وتتولى مهمة التنظيف حسب فترة الاحتفاظ.
